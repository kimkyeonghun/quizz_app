# Content Sources

텍스트 문제는 한국 성인 모임을 기준으로 자체 작성·검수한 콘텐츠입니다. 선수 커리어는 확인 가능한 구단 공식 선수 페이지를 우선 출처로 기록하고 Wikidata의 소속 팀 문장과 시작·종료 시점을 재현 가능한 보조 출처로 저장합니다. `verifiedAt`으로 확인일을 관리하며 현역 선수 데이터는 재배포 전에 다시 수집·검수해야 합니다.

인물 사진은 Wikimedia Commons 파일 설명 페이지에서 퍼블릭 도메인, CC0, CC BY, CC BY-SA 여부를 개별 확인한 뒤 500px 이하 썸네일을 `public/assets/person`에 저장합니다. 저작자·원본·라이선스·수정 내역은 각 문항에 포함되며 정답 공개 후 확인할 수 있습니다. 파일이 없거나 불러오기에 실패해도 게임 화면은 중단되지 않습니다.

추가된 사람 24명과 애니메이션 캐릭터 20개는 친구 모임에서만 쓰는 `private_only` 콘텐츠입니다. 사람 사진은 한국어 Wikipedia 프로필 페이지, 캐릭터 정보와 이미지는 AniList 캐릭터 페이지를 원본으로 기록하며 `public/assets/person/private`에 로컬 저장합니다. 이 44문항은 재배포 가능 라이선스로 간주하지 않으며 공개 저장소·웹 서비스·상업 행사에 사용하지 않습니다.
