# Content Sources

텍스트 기반 데모 문제는 일반 상식과 게임 진행 검증을 위한 자체 작성 콘텐츠입니다. 선수 커리어 문제의 `source`에는 해당 선수와 관련된 구단 공식 페이지를 기록하고 `verifiedAt`으로 확인일을 관리합니다.

신규 게임 데모는 `public/assets/new-games`의 직접 제작 SVG와 합성 WAV를 사용합니다. 브랜드, 영화, 음악 이름은 기능 검증용 가상 콘텐츠이며 전통 민요 게임은 제목만 사용하고 그림은 직접 제작했습니다. 실제 운영 에셋은 사용 권한을 확인한 파일만 `public/assets`에 추가하고 각 문제에 `source`, `license`, `credit`을 기록해야 합니다. 파일이 없거나 불러오기에 실패해도 게임 화면은 중단되지 않습니다.
