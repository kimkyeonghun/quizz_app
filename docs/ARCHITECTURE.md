# Architecture

## 구성

- `src/config`: 게임 레지스트리와 JSON 기본 설정 검증
- `src/data`: Zod 문제 스키마, 자동 로더, 필터와 셔플
- `src/game-modules`: 신규 6개 게임의 독립 스키마, 설정, 안내, runtime reducer와 React 화면
- `src/adapters`: 독립 모듈을 현재 레지스트리·스토어·화면에 연결하는 교체 가능한 계층
- `src/store`: 세션·팀·점수·타이머·진행·Undo 상태
- `src/App.tsx`: 화면 흐름과 게임별 표시 어댑터
- `data`: 런타임 문제 데이터
- `scripts`: 데이터 검증과 현황 보고

세 게임 엔진은 어댑터가 제공하는 `engine` 값으로 구분합니다. Speed는 정답/패스 후 즉시 다음 문제로 이동하고, Standard는 문제별 타이머와 사회자 판정을 사용하며, Progressive는 단계 인덱스와 단계별 배점을 추가합니다. 신규 게임의 실제 단계 수는 설정 배열이 아니라 문제 데이터에서 계산해 큐에 저장합니다.

각 `GameDefinition`은 플레이 로직뿐 아니라 목표, 진행 단계, 채점 방식, 진행자 팁을 포함합니다. 게임 선택 후 공통 안내 화면이 이 정보를 렌더링하므로 새로운 게임을 추가할 때 별도 안내 컴포넌트를 만들 필요가 없습니다.

`HostAction`은 팀 ID가 포함된 discriminated union입니다. Zustand 저장소가 액션 직전 상태를 최대 50개 보관해 점수와 문제 진행을 함께 되돌립니다. 플레이 중 고빈도 타이머 값은 세션 복원 대상에서 제외하며, 새로고침 시 안전하게 게임 설정 화면으로 돌아갑니다.

신규 모듈은 `App`, Zustand 저장소, 기존 6개 레지스트리를 import하지 않습니다. 설명 금지어의 공개 상태처럼 게임별로 직렬화해야 하는 값은 `moduleRuntime`과 모듈 reducer로 처리하며 Undo 스냅샷에도 포함됩니다. localStorage 스키마 버전은 2이고 이전 설정에 신규 게임 기본값을 추가하는 마이그레이션을 제공합니다.
