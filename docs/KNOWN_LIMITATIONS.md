# Known Limitations

- 기존 6개와 신규 게임 4개가 활성화되어 있습니다. 이미지 확대는 로고 확대 퀴즈에 통합되었고 설명 금지어는 기본 feature flag가 꺼져 있습니다.
- 신규 미디어는 기능 검증용 가상 샘플입니다. 운영용 로고, 포스터, 음악과 대량 문제 풀은 별도로 준비해야 합니다.
- 현재 로컬 운영 테스트 영화는 최신 한국 영화가 아닌 퍼블릭 도메인 고전 영화이며, 노래 그림도 K-pop이 아닌 퍼블릭 도메인 곡입니다. 메인 환경의 권리 확인된 데이터로 교체해야 합니다.
- 인물 데이터에는 라이선스 문제로 사진 파일이 포함되지 않아 에셋 추가 전에는 대체 화면이 표시됩니다.
- 정답 판정은 음성 인식이나 문자열 자동 비교가 아닌 사회자 판정입니다.
- 브라우저 간 온라인 동기화와 참가자 모바일 화면은 지원하지 않습니다.
- 정적 빌드는 `file://` 직접 열기보다 `npm run preview` 같은 로컬 HTTP 서버 사용을 전제로 합니다.
