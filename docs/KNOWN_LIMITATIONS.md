# Known Limitations

- 신규 미디어 게임은 코드와 구조 검증을 완료했지만 운영용 음원·포스터·로고·그림 데이터는 별도 권리 검수와 로컬 수집이 필요합니다.
- `zoom_image`는 `logo_quiz`로 통합되어 선택 화면에서 숨겨지며 기존 세션 호환만 유지합니다. 설명 금지어는 기능 플래그 기본값이 꺼져 있습니다.
- 음성 인식은 지원하지 않으며 기본 판정 방식은 사회자 판정입니다.
- 직접 입력 모드는 등록 정답과 별칭을 문자열로 자동 비교하지만, `5초 안에 3개`처럼 가능한 답이 열려 있는 문제는 사회자 판정만 지원합니다.
- 팀 도전은 참가자용 버저가 아니라 사회자가 화면에서 도전 팀을 지정합니다.
- 인물 이미지의 저작권 외 초상권·상표권 등은 사용 지역과 목적에 따라 별도 확인이 필요합니다.
- `private_only` 인물·캐릭터 이미지는 친구 모임용 로컬 이용만 전제로 하며 외부 배포 권한을 검증한 콘텐츠가 아닙니다.
- 브라우저 간 온라인 동기화와 참가자 모바일 화면은 지원하지 않습니다.
- 사회자 콘솔은 같은 브라우저의 팝업 창을 사용하므로 최초 실행 시 사이트 팝업 허용이 필요할 수 있습니다.
- 정적 빌드는 `file://` 직접 열기보다 `npm run preview` 같은 로컬 HTTP 서버 사용을 전제로 합니다.
