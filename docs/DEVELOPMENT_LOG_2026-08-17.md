기존 6개 MVP 게임을 실제 친구 모임에서 안정적으로 진행할 수 있는 수준으로 고도화했다. 문제 수를 늘리고 게임별 규칙과 상태 전이를 명확히 했으며, TV가 있는 환경과 노트북 한 화면만 사용하는 환경을 모두 지원하도록 진행 방식을 확장했다. 마지막으로 전체 문제 데이터를 조회하는 읽기 전용 관리자 페이지를 추가했다.

## 게임 진행 구조

공통 진행 상태를 `ready → preview/active → attempt → revealed`로 정리했다.

- `ready`: 시작 전 문제 비공개
- `preview`: 몸으로 말해요 설명자 확인 시간
- `active`: 문제 진행 및 타이머 동작
- `attempt`: 도전 팀의 답을 판정하며 타이머 일시정지
- `revealed`: 정답과 출처 공개

라운드 타이머와 문제·단계 타이머를 분리했으며, 점수·타이머·단계·팀 잠금·문제 이동을 Undo로 함께 복구한다.

## 게임별 확정 규칙

### 인물 퀴즈

- 도전 팀의 60초 속도전
- 정답 +1점, 무감점 패스
- 시작 전 사진 비공개
- 사회자 판정 또는 참가자 직접 입력

### 몸으로 말해요

- 60초 속도전
- 문제마다 설명자에게 제시어를 3초간 보여주는 동안 라운드 시계 정지
- 진행 시작 후 제시어 숨김
- 말·소리·글자·숫자·도구 사용 금지
- 정답 +1점, 무감점 패스

### 네 글자 이어말하기

- 앞 2음절을 보고 등록된 뒤 2음절을 답하면 +1점
- 직접 입력에서는 뒤 2음절과 완성된 4글자를 모두 인정
- 동일 앞말 중복 금지
- 무감점 패스

### 5초 안에 3개

- 라운드당 10문제
- 공개와 동시에 기본 5초 타이머 시작
- 중복 없는 유효 답 3개면 +1점
- 시간 3~15초, 필요 답변 2~5개 설정 가능
- 가능한 정답이 열려 있는 자유응답형이므로 사회자 판정만 지원

### 3단 힌트

- 모든 팀 경쟁, 라운드당 5문제
- 단계별 15초, 3/2/1점
- 도전 팀 지정 시 타이머 정지
- 오답 팀은 현재 단계에서만 잠기며 다음 단계에서 복귀
- 시간 만료 또는 모든 팀 잠금 시 다음 단계 자동 진행

### 선수 커리어 맞히기

- 모든 팀 경쟁, 라운드당 5문제
- 실제 순서의 전체 클럽 경력을 한 번에 공개
- 문제당 20초, 정답 +1점
- 오답 팀은 해당 문제에서 잠김
- 시간 만료 또는 모든 팀 잠금 시 정답과 출처 공개

## 진행 방식 확장

### 사회자 콘솔

플레이 화면의 모니터 아이콘으로 별도 팝업을 연다. 같은 Zustand 저장소를 사용하므로 별도 서버 없이 참가자 화면과 실시간으로 상태가 공유된다.

사회자 콘솔에서 확인 가능한 정보:

- 정답과 허용 답안
- 5초 게임 판정 예시와 기준
- 3단 힌트 전체 내용
- 선수 전체 경력
- 타이머와 도전·잠금 상태
- 정답·오답·패스·다음 문제·Undo·라운드 종료 조작

### 참가자 직접 입력

게임 설정의 `정답 판정 방식`에서 선택한다.

- 지원: 인물, 몸으로 말해요, 네 글자, 3단 힌트, 선수 커리어
- 미지원: 5초 안에 3개
- Unicode NFC, 공백, 기호, 대소문자를 정규화해 비교
- `answer`와 `acceptedAnswers`를 모두 인정
- 전 팀 경쟁 게임은 답을 제출할 팀을 선택
- 진행형 게임의 오답은 기존 팀 잠금 규칙 적용

### 인물 콘텐츠

- 재배포 가능한 Wikimedia Commons 기반 인물 115명
- 친구 모임용 로컬 전용 사람 24명
- 로컬 전용 애니메이션 캐릭터 20개
- 로컬 전용 콘텐츠는 `usageScope: "private_only"`와 `PRIVATE LOCAL USE`로 표시
- 문제 필터에서 `로컬 전용 문제 포함`을 해제하면 재배포 가능한 115문항만 사용

애니메이션 캐릭터에는 피카츄, 도라에몽, 짱구, 손오공, 루피, 조로, 나루토, 사스케, 코난, 토토로, 세일러 문, 에드워드 엘릭, 에렌 예거, 리바이, 탄지로, 네즈코, 고죠 사토루, 아냐 포저, 하울, 치히로가 포함된다.

## 영속 상태와 마이그레이션

Zustand 영속 상태 버전을 5까지 올렸다.

- 기존 팀 이름·색상·점수 보존
- 기존 사용 문제 기록 보존
- 플레이 도중 새로고침 시 안전하게 게임 설정으로 복귀
- 과거 선수 커리어 4단계 설정을 새 단일 단계 규칙으로 교정
- 직접 입력 모드와 로컬 전용 문제 필터 기본값 추가

## 주요 파일

- `src/App.tsx`: 화면 흐름, 게임 UI, 사회자 콘솔, 직접 입력, 관리자 페이지
- `src/styles.css`: 플레이·사회자·관리자 반응형 스타일

- `scripts/data-utils.ts`: 데이터 전수 검증
- `scripts/data-report.ts`: 게임별 데이터 현황 보고

- `scripts/seed-private-person-content.mjs`: 로컬 전용 사람·캐릭터 생성

## 개발 환경 메모

현재 WSL의 기본 `npm`이 Windows 실행 파일로 연결되어 있어 검사에는 임시 Linux Node.js 환경을 사용했다.

- Node.js: `/tmp/quizz-node/bin`의 v22.18.0
- Playwright 라이브러리: `/tmp/quizz-browser-libs/root/usr/lib/x86_64-linux-gnu`

다음 세션 전에 Linux용 Node.js LTS/npm을 WSL에 영구 설치하는 것이 좋다.
