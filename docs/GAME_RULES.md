# Game Rules

모든 게임은 `ready → preview/active → attempt → revealed` 흐름을 사용하며 시작 전에는 문제를 표시하지 않습니다.

- 인물 퀴즈: 도전 팀의 60초 속도전입니다. 정답은 1점, 패스는 무감점입니다.
- 몸으로 말해요: 제시어를 3초간 설명자에게만 보여준 뒤 숨깁니다. 미리보기 동안 라운드 시계는 멈추며 말·소리·글자·숫자·도구는 금지합니다.
- 네 글자 이어말하기: 앞 2음절에 등록된 뒤 2음절을 이어 말합니다. 정답은 1점, 패스는 무감점입니다.
- 5초 안에 3개: 도전 팀이 10문제를 풀며 중복 없는 유효 답 3개를 말하면 1점입니다.
- 3단 힌트: 모든 팀이 참여하며 단계별 15초와 3/2/1점을 적용합니다.
- 선수 커리어: 실제 순서의 전체 클럽 경력을 한 번에 공개하며 20초 안에 맞히면 1점입니다.
- 음악 전주: 전주를 3단계로 길게 재생하며 기본 3/2/1점을 적용합니다.
- 로고 확대: 로고의 작은 영역, 중간 영역, 전체를 10초씩 공개하며 기본 3/2/1점을 적용합니다.
- 영화 포스터: 제목 영역을 가린 포스터를 20초 동안 보고 영화 제목을 맞히면 1점입니다.
- 노래 그림: 가사의 장면과 정서를 해석한 완성 그림 한 장을 25초 동안 보고 곡명을 맞히면 1점입니다.

전 팀 경쟁 게임에서 도전 팀을 선택하면 타이머가 멈춥니다. 3단 힌트의 오답 팀은 현재 단계에서만 잠기고 다음 단계에서 다시 참여합니다. 선수 커리어의 오답 팀은 해당 문제에서 잠깁니다. 모든 팀이 잠기거나 마지막 제한시간이 끝나면 정답을 공개합니다. 판정, 패스, 단계 이동, 문제 이동은 Undo 대상입니다.

플레이 화면의 `사회자 화면 열기` 버튼은 별도 팝업에 정답, 허용 답안, 전체 힌트, 판정 예시와 진행 조작을 표시합니다. 참가자용 TV 화면에는 정답 공개 전까지 이 정보가 나타나지 않습니다.

정답 데이터가 있는 인물 퀴즈, 몸으로 말해요, 네 글자 이어말하기, 3단 힌트, 선수 커리어와 신규 미디어 게임은 `참가자가 직접 입력` 모드를 지원합니다. 별칭·공백·기호·대소문자를 정규화해 자동 판정하며 네 글자는 뒤 2음절과 완성어를 모두 인정합니다. 전 팀 경쟁 게임은 답을 입력할 팀을 먼저 선택하고 오답이면 기존 잠금 규칙을 적용합니다. `5초 안에 3개`와 설명 금지어는 사회자 판정을 유지합니다.
