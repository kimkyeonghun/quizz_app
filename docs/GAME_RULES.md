# Game Rules

- 속도형: 인물, 몸으로 말해요, 네 글자 이어말하기. 라운드 전체에 하나의 타이머를 사용합니다.
- 일반형: 5초 안에 3개. 문제마다 타이머를 다시 시작하며 사회자가 성공을 판정합니다.
- 단계형: 3단 힌트, 선수 커리어. 힌트를 더 열수록 현재 단계 점수가 낮아집니다.
- 미디어 일반형: 영화 포스터와 노래 그림. 제목이 가려진 포스터 또는 가사를 해석한 완성 그림 한 장을 보고 문제별 제한 시간 안에 답합니다.
- 미디어 단계형: 음악 전주와 로고 확대 퀴즈. 단계가 진행될수록 재생 구간 또는 로고 영역이 넓어지고 배점은 낮아집니다.
- 설명 금지어: 설명자가 금지어를 확인한 뒤 진행자가 수동으로 숨기고, 제한 시간 동안 제시어를 설명합니다. 기본 배포에서는 비활성입니다.

시간과 점수는 시작 전에 변경할 수 있습니다. 오답 정책은 상대팀 기회, 같은 팀 재도전, 문제 종료, 사회자 선택 중 하나입니다. 판정, 패스, 단계 이동, 문제 이동은 Undo 대상입니다.
